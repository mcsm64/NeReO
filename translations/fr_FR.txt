# en: NeReO now reads Format=Flowed (RFC 3676), the way almost every modern newsreader states where a paragraph really ends. # en: STARTTLS now follows both halves of RFC 4642 instead of one. If a server refuses STARTTLS before the handshake, NeReO may carry on unencrypted, as the standard allows, and that is unchanged. But if the server accepts (382) and the handshake then fails, RFC 4642 says both sides SHOULD close the connection - and until now NeReO carried on in cleartext instead. # en: TLS trust is now something you GRANT, not something you are handed. The normal path is unchanged - Android's certificate check plus the host name check, exactly as before.
